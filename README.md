# BrainBoostClient
Frontend oficial del proyecto BrainBoost, desarrollado para ofrecer una experiencia moderna, rápida e intuitiva a los usuarios.

## 🧠 Acerca de y el porque de este proyecto
Durante mi TFG en el Ciclo Formativo de Grado Superior en Desarrollo de Aplicaciones Multiplataforma desarrollé BrainBoost, una aplicación de estudio mediante flashcards que ayuda a memorizar conceptos clave de forma rápida. La idea nació de mi experiencia estudiando con Anki, herramienta que me inspiró a crear mi propia versión.

La asignatura de Programación de Servicios y Procesos (PSPR) despertó mi interés por la arquitectura cliente-servidor y los sockets, lo que me llevó a diseñar dos aplicaciones: un cliente móvil y un servidor que se comunican entre sí.

## 🛠️ Tecnologias empleadas
 - Java
 - Kotlin
 - XML
 - SQLite
 - Git
 - GitHub

Desarrollado en Android Studio.

## 🎭 Funcionalidades
- Gestión de mazos y flashcards (crear, modificar y eliminar).
- Registro y login de usuarios.
- Sesiones de estudio con flashcards.
- Exportación e importación de mazos en formato CSV para compartir o guardar.
